# CLAUDE.md

Concept website for **Grain & Joint**, a fictional carpentry studio that makes built-in furniture: wardrobes, kitchens, wall units, desks, tables and window seats. The site is the author's personal project; the brand is invented. Plain HTML, CSS and ES modules in `site/`, with no build step. Three.js 0.169.0, GSAP 3.12.5 (with ScrollTrigger) and Lenis 1.1.13 load from jsDelivr through an import map, at exactly these versions.

## Run and test
- `python tools/dev_server.py` serves `site/` on http://localhost:5174 (set `PORT` to change it).
- `node --test` (from the repo root) runs the unit tests. They cover the pure modules in `site/js/configurator/` (`model.js`, `pricing.js`, `share.js`).
- `node tools/smoke.mjs` loads every page in Playwright and fails on console errors (Chromium lives in /opt/pw-browsers).

## Conventions
- `CONTRACTS.md` is the source of truth for the data model, pricing and the 3D API. Change it first, then the code.
- Model and pricing modules are pure: no DOM, no Three.js, so Node can test them.
- Model lengths are in cm; the 3D scene uses metres.
- Page CSS uses only the tokens in `site/css/base.css`.
- Every animation respects `prefers-reduced-motion`.
- Images: Unsplash photos only, each credited in `README.md` and in `site/credits.html`. Everything else is a 3D render or CSS.
- The Home hero (`js/hero.js`) shows a preloader (`#preloader`) until every frame of `site/assets/hero-frames/` (a Cycles-rendered image sequence of the assembly, `tools/blender/film.py`) has loaded, then scrubs them by scroll with `js/hero-frames.js`. Only if the frames cannot load does it import the live scene in `js/hero3d.js`, which loads `site/assets/3d/hero.glb` (Blender, Poly Haven CC0 textures, Cycles-baked room lightmaps) over its procedural scene. The assets are generated by `tools/blender/` (see its README); panel names and sizes there mirror `createHero()` in `site/js/hero3d.js`, so change both together. `hero-still.webp` is the Cycles render used when WebGL is unavailable, and `ba-before.webp` / `ba-after.webp` (film.py --ba) feed the Home before/after slider. Keep Three.js off the Home page's normal path.
- Performance: no requestAnimationFrame loop may run while nothing changes, scroll handlers write styles only when a value changes, and looping CSS animations get paused off screen (`.is-offscreen`, app.js).
- SEO: each page head has a canonical URL and Open Graph tags; `robots.txt`, `sitemap.xml` and `404.html` live in `site/`. `_shell.html` is a template and is not deployed.
- The planner's contact step (the guided flow's last question; the tabbed view's "Send to the workshop" opens it) never sends data anywhere; it only shows a success state. `contact.html` has no form: it points to the planner, email, phone and the studio details, and forwards old `#p=` / `#design=` links to `planner.html`.
